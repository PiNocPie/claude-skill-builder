# Daily Standup ภาษาไทย

## ทำอะไรได้
แปลงสิ่งที่คุณทำ ให้เป็นสรุป standup 3 ส่วน เมื่อวาน / วันนี้ / ติดอะไร พร้อมโพสลงแชตทีมได้เลย

## เหมาะกับใคร
พนักงานออฟฟิศ ทีม dev ทีม remote ที่มีประชุมเช้า

ใช้ตอน:
- ก่อนประชุม standup แล้วยังไม่ได้เรียบเรียง
- อยากได้สรุปสั้นๆ โพสในแชตทีม

## บอก Claude ยังไง
```
"standup: เมื่อวานทำ X วันนี้จะทำ Y ติด Z"
```

## ขั้นตอนการทำงาน
1. รับสิ่งที่ผู้ใช้พิมพ์มา (อาจไม่เป็นระเบียบ)
2. จัดเป็น 3 หัวข้อ เมื่อวาน / วันนี้ / ติดอะไร
3. เขียนสั้น กระชับ เป็น bullet
4. ถ้าไม่มีข้อมูล "ติดอะไร" ให้ถามก่อน อย่าเดา

## ที่ต้องระวัง
อย่าแต่งเติมงานที่ผู้ใช้ไม่ได้บอก สรุปเฉพาะที่ให้มาเท่านั้น
